# Rebuilding dose 0.24.0 spectral engine

0.24 adds the explicit `spectralIntent` recipe field. Missing intent means the original path; new UI selections use `natural`. Natural disables automatic remetering and scanner unsharp, uses the original Scene Latitude equations before film, and routes high/shadow controls to those float parameters. It does not rewrite film/paper profiles or insert an 8-bit DNG conversion. Original-parameter RGBA16 output was compared against the packaged 0.23 host on two JPEGs and two DNGs; all four differences were zero.

The new Vulkan shader is `engine/src/shaders/vulkan/spk_scene_latitude.comp`; CMake compiles it into the bundled runtime. `gpu_vulkan_pointwise.cpp` adds 72 independent double-precision cases (3 norms × 3 rolloffs × 2 activation cases × 4 whole/split/strip shapes, each 273 pixels plus output guards). `windows_feature_boundaries.cpp` enables nonzero rooms and renders an actual frame. Two additive PRINT fields expose the existing scanner radius/amount; see `desktop/HOST-PROTOCOL.md`. Current gates: native CTest, `tests/natural.test.cjs`, `tests/natural-native.cjs`, `tests/natural-desktop.cjs`, and `tests/fidelity.cjs` with `DOSE_REFERENCE_HOME` pointing to the 0.23 native runtime. `DOSE_NIGHT_INPUT` optionally supplies a local lantern source for the diagnostic crop comparison. Test fixtures are external/local test assets; personal photos and user profiles are excluded from the source archive.

Natural DNG uses the existing compatible16 LibRaw decode, not unbounded sensor headroom. HEIC is the existing SDR decoder. Windows formula/original-mode checks do not establish macOS Metal pixel parity. Fotufilm is not bundled.

0.19 adds local square composition with a selected-photo magnifier and nine-tile export. `share-grid.js` contains geometry and clean photo/lens drawing helpers; `share-composer.js` owns the isolated modal snapshot, preview and streamed 4320px sRGB composition. Source images use the existing tagged photo protocol, with bounded 2400/3200/4320/6000 resolution buckets for export. Only one decoded export bitmap is retained at a time. `grid-export.cjs` validates the supplied PNG and creates nine 1440px JPEGs with ICC in a unique, user-selected child directory. A single-use main-process token binds that write to the selected destination. No original source, scene geometry or grading is modified. Tests: `share-geometry.test.cjs`, `grid-export.test.cjs`, `share-grid-desktop.cjs`. The native engine and existing per-photo grading/export modules are unchanged; prior fidelity evidence remains versioned separately.

0.18 merges the native title bar and two app header rows into one 60px Windows title-bar-overlay toolbar. It changes BrowserWindow presentation and app layout, removes redundant labels and stage hints, and retains native caption buttons. The film-processing modules and all 87 native runtime files are unchanged. `single-row-desktop.cjs` checks the packaged toolbar, native overlay safe area, file actions, zoom/light controls, selected-only grading, layouts, minimum window, native window states and fullscreen return. Numeric film fidelity is retained with its original version provenance.

The native-window capture in that development test uses the locally installed screenshot Skill's `scripts/take_screenshot.ps1`; set `DOSE_SCREENSHOT_HELPER` to its absolute path if needed. The included `tests/capture-native-window.ps1` sets per-monitor DPI awareness before calling it. This is a verification dependency only; running dose does not require the Skill or PowerShell screenshot helper.

0.17 adds an app-side Moments magazine layout: all library photos, exactly nine balanced pages when at least nine photos exist, otherwise one page per photo. It reuses the editorial composition grammar and displays the pages in 3x3 order; repeated layout varies composition. Includes previously unplaced photos and removes duplicate canvas placements. The full-library scope is explicit and does not alter per-photo grading. Import updates, persistence and undo are covered by `moments-layout.test.cjs` and `moments-desktop.cjs`. The 87 native runtime files and film pipeline remain unchanged from 0.16; its fidelity report is retained with provenance, while the new layout is verified against the current packaged app.

0.16 retires the negative-EV/chroma auto-fit v1 path at the app boundary. Defaults are off; legacy natural recipes are backed up byte-for-byte before persistence and sanitized to neutral auto-fit while retaining manual sliders. Optional v2 is brightness-only (0..0.75 EV, saturation fixed at 1), validates actual native output tonal separation/clipping, and never intentionally darkens an image. The native film engine remains unchanged. Focused tests: `auto-fit.test.cjs`, `brightness-safety-native.cjs`, `brightness-safety-desktop.cjs`, and `auto-fit-desktop.cjs` (current v2 lifecycle). Historical v1 code/measurements are retained only as regression evidence.

0.15 changes app-side adaptive magazine composition, viewport-fitting layout, persistence and display geometry. The packaged native engine and stock data remain byte-identical to 0.13. Its prior native fidelity/CTest evidence is retained with explicit version provenance; packaged layout/interaction checks are rerun for 0.15. Composition decisions are in `docs/reference-magazine/`. Focused tests: `editorial-layout.test.cjs`, `viewport-layout.test.cjs`, `adaptive-layout-desktop.cjs`, `viewport-layout-desktop.cjs`.

The source archive contains `LightTable-Windows`, `SpektraLab-port`, and `spectral-tools` sibling directories. Engine source is upstream JamesQiu2005/SpektraLab commit `99c2d5c9883be485085895157279cc7c4eaa8db6` plus the small documented portability/precision changes. The material profiles have not been modified. LibRaw 0.22.2 and Vulkan-Headers at `b5c8f996196ba4aa6d8f97e52b5d3b6e70f7e4e2` are included as source. No private photos, application userdata, credentials or caches are included.

0.13 adds an optional dose output adaptation after the original Layer 2 grade. It decodes ProPhoto into linear float, applies a black/white anchored luma correction and bounded chroma scaling, then re-encodes before display/export. The original film core and material profiles are unchanged. `auto_fit_active=false` preserves 0.12 output. Analysis and per-photo persistence are in `src/auto-fit.js`, `src/film-worker.cjs`, and `src/renderer.js`; native correction is in `engine/host/output.cpp`. Focused checks are `tests/auto-fit.test.cjs`, `auto-fit-native.cjs`, `auto-fit-spectral.cjs`, and `auto-fit-desktop.cjs`.

Tools used on Windows x64 (tools are build requirements, not app runtime requirements):

1. Download `llvm-mingw-20261020-ucrt-x86_64.zip` from https://github.com/mstorsjo/llvm-mingw/releases/tag/20261020 and extract under `spectral-tools/`.
2. Download `glslang-16.6.0-windows-x86_64-release.zip` from https://github.com/KhronosGroup/glslang/releases/tag/16.6.0 and extract so `spectral-tools/glslang/bin/glslang.exe` exists. Consult `build-inputs.json` for the exact archived asset name/hash used.
3. Install CMake 4.4.4 and Ninja 1.13.2 with `python -m pip install --target spectral-tools/python cmake==4.4.4 ninja==1.13.2` from the source archive root. Python is only used to provision these tools.
4. In `LightTable-Windows`, run `powershell -ExecutionPolicy Bypass -File build-spectral.ps1`. It configures CMake, builds the host with static runtime, runs native tests, and stages executable/resources. Requires a Vulkan GPU for native tests. Do not disable tests to claim a validated build.
5. With Node.js/npm installed: `npm ci`, `npm test`, `node tests/spectral-native.cjs`, `npm run package`. The app includes staged native binaries for convenience, but the preceding steps rebuild them from the supplied source. `npm start` starts development mode.

`tests/spectral-desktop.cjs` additionally needs `tests/heic-fixtures/example.heic` from https://github.com/strukturag/libheif/blob/master/examples/example.heic. The ordinary desktop suite generates fixture JPGs when needed; use `npm run test:desktop` first. Set `LIGHTTABLE_EXECUTABLE` to the packaged dose.exe to exercise the shipped build. Every desktop test uses a separate userdata profile and does not read personal photos.

Build environment tested: LLVM MinGW Clang 23.1.4, Windows x64, NVIDIA RTX 5070. The host dynamically uses the vendor's installed Vulkan driver; it does not bundle a driver. Vulkan shader tests passing do not establish bit-identical parity to every macOS/Python upstream path.

Corresponding source of LLVM/MinGW runtime: https://github.com/mstorsjo/llvm-mingw/tree/20261020 and the toolchain's `LICENSE.TXT` (Apache 2.0 with LLVM exceptions and additional component notices). System Windows libraries are not redistributed.

DNG verification: tests/dng-desktop.cjs uses Apple-iPhone-12-Pro.DNG and tests/dng-fixtures/Ricoh-GR-III.DNG from https://github.com/tellodaniel/revelraw-sample-raw-files/releases/tag/v1 (CC0 samples originating from raw.pixls.us). Fixture images are not included in the app or source archive.

0.10.0 fidelity checks: `node tests/fidelity.cjs` uses `DOSE_REFERENCE_HOME` (default: prior outputs/v0.9.1/dose-win32-x64/resources/spectral) for the independently invoked pre-change native host. This is a Windows adapter oracle, not a Metal execution oracle. `node tests/fidelity-desktop.cjs` validates DNG live preview, high-precision TIFF and explicit legacy migration. The two fixture JPEGs used are 01-valley.jpg and 06-castle.jpg from the supplied verification assets; DNG source links are above. Set LIGHTTABLE_EXECUTABLE to the packaged executable for the desktop check. New Layer2 code in host/output.cpp/main.cpp retains float encoded RGB through output color conversion; tests compare six nonzero grade combinations with an independent translation of the Metal shader.

0.11.0 adds display-only film-frame.js and editorial-layout.js. `node tests/editorial-desktop.cjs` validates layout/undo/selected scope, actual canvas pixel neutrality, export independence and persistence. `node tests/stage-alignment.cjs` checks the four positive-film scan branches and cached-negative reprinting. No profile data or native binary was changed in 0.11.0.

0.11.1 stages the upstream `engine/resources_product/profiles` overlay and its notice in addition to the 28 base profiles, as upstream `engine/build.sh bundle` does. The base neutral-filter table is not overwritten: the client explicitly sends the original Multigrade filter-2 neutral pack for silver film/paper pairs and applies the original per-stock grain scale. The native executable is unchanged. `node tests/black-and-white.cjs` additionally compares all 33 profile JSON contents against the supplied 1.3.3 bundle (five product profiles also byte-identical), checks silver neutrality, original default grain, mid-grey density, independent filter-2 parameter requests, DNG TIFF output and transition back to colour. That optional test needs the user's local DMG extracted at `work/dmg-audit/app-only`; the copyrighted application bundle itself is not redistributed. The same product profiles are already included in the public corresponding source archive.

The upstream release tag `spektralab-v1.3.3` is `c52657409ad8d4c1bcd2e581879891ae32e8352f`; its engine and modern_UI Git trees are identical to baseline 99c2d5c. This source match and the bundle resource comparison do not substitute for executing Metal on macOS with the same input image.

0.12.0 corrects the host export transform to request `{"lightness_compression_active":false}`, as `modern_UI/.../Canvas/ColourManagement.swift` does. Its PNG16 render format carries the working-space samples with their ICC directly to the browser CMS. The canvas no longer uses the export CAM16 conversion as a display transform. The encoded preview is sample-identical to the engine's graded RGBA16 result; a P3 canvas retains a wider display gamut. Exports remain explicitly colour-managed for their destination. The native host is rebuilt and the 15 native CTest cases pass.

Focused checks: `node tests/colour-output.cjs` compares working-space results against the prior binary, checks PNG16 sample equality and records before/after sRGB proof changes; `node tests/colour-desktop.cjs` checks PNG MIME, ICC rendering, P3 canvas, DNG slider frames, selected-only edits and no loading text. The two CMS implementations are not bit-identical (measured max 4/255, mean 0.455/255 in the fixture); no claim of ColorSync/Chromium pixel identity is made.

Independent model checks are included under `tests/reference/`, with their own README and dependency versions. They compare the native C ABI against a separately executed public spektrafilm CPU runtime, not a second invocation of the same host. Recreate the pinned reference checkout and install only the documented development dependencies in a separate environment. Python remains unnecessary to run the app.
