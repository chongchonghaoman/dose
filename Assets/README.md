# 观片台图标

用户确定的「透光胶片」方向：明亮奶白灯箱、深色胶片框、抽象琥珀与青绿色透光色块。没有具体山水或人物内容。

- `AppIcon.png`：1024 × 1024 RGBA母版，外围透明。
- `AppIcon.icns`：macOS图标，覆盖16、32、128、256、512点及对应2×尺寸。
- 重建ICNS：在项目根目录运行 `zsh scripts/generate-app-icon.sh`；使用系统sips和iconutil，不调用图像服务。
- 图像由用户授权的image2.5服务生成，经本地透明边缘处理。未使用用户照片或第三方品牌标识。
- 制作日期：2026-10-25；视觉版本v2。
