# dose · 那些日子，慢慢显影

Windows 0.24.0。一个本地照片观片台，带连续调色预览、胶片模拟、放大镜和幻灯机。

## 0.24.0：自然显影

新选择「胶片与相纸」时默认使用「自然显影」：保留原照片已有曝光，不再把夜景整体测成中灰；在浮点胶片处理之前柔和压缩高光、展开暗部。高光、阴影滑块控制这一段场景宽容度，避免成片已经失去层次后再做补偿。默认颗粒 12、光晕 5、辉光 0，并关闭二次扫描锐化。

已有胶片配方继续使用「原版流程」。选中照片后，在「显影」中切换「自然显影」即可应用新方式，仍保留所选胶片、相纸与手动基础参数；只有尚未自行调整的颗粒等默认值会随模式切换。重置胶片和双击滑块按照当前显影方式还原。自然显影中不叠加旧亮度辅助。操作仅影响所选照片，支持撤销及连续预览。

Windows Vulkan 新增 Scene Latitude 计算，与源码公式做独立 float64 对照；材料曲线未修改。DNG 继续使用原生 LibRaw 高精度路径、ICC 管理预览及原尺寸 TIFF16 导出，HEIC 继续使用现有 SDR 解码路径。本版没有接入 Fotufilm，也不宣称已获得 macOS/Metal 成片的逐像素一致性。

## 0.23.0：九宫格均衡拼版与更大的照片

朋友圈分割改用照片拼版网格：通过等高行、等宽列和统一沟槽，根据原图比例反算尺寸。移除固定大块页眉留白，以及将一张照片分配成巨大主图、其他照片被挤小的分区。算法同时评估画面占用率、照片面积差和九个分格的覆盖率，换版仍须通过质量约束。

杂志使用均衡的横向分带，九页杂志将照片分布到九个区域，适应方框使用全幅拼版，网格以等高行为主、联系表以等宽列为主。分带和九区均衡分配照片数量，减少连续竖图或横图造成的局部空洞。照片保留完整原比例，所有照片都参与，不通过裁切、拉伸或漏掉照片换取占用率。少于九张时，使用连续拼版充分利用方框。

下次进入朋友圈模式即生成新排版；独立方框、自由放大镜、保存恢复和九张导出继续保留。灯箱本身的杂志网格与调色不变。

进入时会只读检查原片是否可读取。已移动、删除或无法访问的原片会明确显示数量，朋友圈仅编排可用照片，避免空位及整组导出失败；灯箱中的原记录保留，重新导入或恢复原片后可再次参与排版。

## 0.22.0：独立的朋友圈分割模式

底栏「朋友圈分割」进入独立的 1:1 方形画布，使用胶片库全部照片（包括未放上灯箱的照片）重新编排。这里不再裁切原灯箱画面，也不改变灯箱照片、页面、视角或调色。模式内可切换杂志、九页杂志、适应方框、网格、联系表，再点「换一版」重排。

杂志与适应方框使用 12 栏与水平基线；九页杂志将照片均衡分成最多九组，置于同一正方形的 3×3 区域，各组遵守局部网格。网格与联系表采用有统一沟槽的等分模块。照片保持完整原比例，最终总画布始终为 1:1。

直接拖动圆镜可自由移动，拖动镜面边缘改变大小，滚轮调整 1–8× 倍率。点画布空白处可将镜面移到那里；「对准照片」仅用于快速定位，后续移动不受该照片位置限制。也可用方向键移动，Shift 加速，方括号改变镜面大小，加减键调整倍率。

排版和镜面位置、大小、倍率、底色与分割线偏好独立保存，返回灯箱或重启后可继续。导出按同一方形构图渲染 4320×4320，再切成 01.jpg–09.jpg，每张 1440×1440、JPEG 95、4:4:4、ICC sRGB。圆形镜面保留，分割辅助线与操作界面不进入图片。DNG、HEIC 沿用现有影像路径，原文件不改写。

## 0.21.0：网格约束的杂志构图

杂志、九页杂志、单页重排及适应窗口共用 12 栏网格和水平基线。页边距、父栏沟槽、照片分组与跨栏都有共同基准，取消随机偏移、随机分割比例和随机靠边位置。照片的实际左右边缘落在列边，顶部落在基线上，完整保留原比例；底边随原图比例自然结束，不强制裁切。

不同版式用跨栏、空栏、主图和辅助组形成主次；换版在明确的模块方案内变换。照片较多或画幅较窄时，使用父栏内的等分子栏，保留 12 个父栏的边缘，统一各层级沟槽。这里的智能适配依据照片数量与横竖比例，没有增加人物或场景语义识别。

已有台面打开时保留当前位置。选中页内照片点击「重排本页」，或点击「一键排版」，即可生成新的网格构图；支持撤销重做。单页重排仍只改变这一页，调色和其他页面保持原值。

## 0.20.0：单页重新排版

在「杂志」或「九页杂志」中，选中某一页内的照片，再点浮动工具条「重排本页」。程序根据这一页全部照片的数量和横竖比例重新评估构图；即使只选中一张，也会编排它所在的整页。再次点击可继续换版。

该页的照片、纸张位置、尺寸及页码保留；其他页面、台面缩放、调色和原文件不改动。选中状态保留，支持 Ctrl+Z 撤销、Ctrl+Shift+Z 重做及重启保存。同页多选可以重排，跨页多选时按钮禁用，避免误改多页。「一键排版」仍按原有范围生成整体排版。

## 0.19.0：朋友圈分割与圆形放大镜

先在台面选中一张照片，再点底栏「朋友圈分割」。取景窗口围绕所选照片打开，显示台面的局部构图及圆形放大镜；拖动画面平移取景，滚轮或「取景范围」调整大小。点选预览中的照片或切换「对准照片」可改变镜面目标，并可调整倍率、镜面大小、浅／深底色。

点击「导出九张」，选择本机文件夹。程序按取景范围单独渲染 4320×4320 的正方形画面，再从左到右、从上到下切成 `01.jpg`–`09.jpg`，每张 1440×1440，JPEG 95、4:4:4、嵌入 sRGB ICC。每次创建独立子文件夹，里面只有九张图片，可按文件名顺序发布。

圆形镜面与边框保留在成片中；分割辅助线、选择框、灯箱齿孔、纸页页脚和工具栏不进入导出。取景与导出不改变原台面的照片位置、调色或原文件。关闭并再次打开可保留本次会话的取景；重新在台面选择照片后，可从新目标开始。

照片重叠时，所选照片在镜面内优先显示；镜面外保持原有摆放层级。

照片从现有调色路径按实际输出所需尺寸读取，每次只解码一张高分辨率图像参与合成，减少大图库的峰值内存占用。分享输出为 8 位 sRGB JPEG；原有 DNG 高精度处理及 TIFF16 导出继续使用独立照片导出入口。

此前将全部照片编排成九页的「朋友圈」排版保留，并在排版下拉菜单中标为「九页杂志」，与新的局部九宫格导出区分。

## 0.18.0：单行顶栏

将品牌、文件操作和观片工具合并为一条 60px 顶栏，只保留一个 dose 标志。Windows 原生窗口按钮与工具栏同排，保留拖动窗口、最大化、最小化和关闭。移除重复标语、「透射灯箱 / 本地照片空间」标签，以及灯箱底部的台面计数和常驻操作提示。

小窗口下压缩间距，灯光按钮保留图标与悬停提示，放大镜倍率、缩放、亮度和调色入口仍可使用。保存状态通过无障碍状态区保留，界面不再常驻显示保存过程。朋友圈、杂志、适应窗口和调色功能延续。

## 0.17.0：朋友圈九页杂志

在「一键排版」旁的排版方式中选择「朋友圈」。始终使用胶片库全部照片，包括未放上台面的照片，不受当前点选范围影响；同一照片的重复摆片只保留一张。照片达到九张时固定编排成九页，按 3×3 顺序在灯箱上展示；不足九张时每张独立成页，不重复照片、不补空白页。

每页沿用杂志的纸色、留白、局部对齐和大小节奏，按照片横竖比例选择构图。照片均衡分配到九页，数量最多相差一张；照片再多也不会增加第十页，因此每页的照片会更密、尺寸更小，可以放大查看。每张照片完整显示，不裁切或改变调色。

再次点「一键排版」会换一组构图；当前模式下新增照片会自动并入九页。支持撤销/重做和重启保存。原有杂志仍按每页最多八张分页，适应窗口保持其原有行为。本次新增的是灯箱排版方式，照片导出仍为逐张照片，不会自动生成整页分享图。

## 0.16.0：恢复原版测光与胶片层次

修复 0.13–0.15 的自动适配对部分照片二次压暗、降低饱和度的问题。旧算法把原片亮度当成目标，会抵消胶片引擎已经完成的测光。现在默认关闭额外补偿，保留原版胶片、相纸和测光的处理结果。

旧版保存的自动补偿会在启动时停用；迁移前将原始台面文件逐字节备份到本地图库的 `backups/table-before-auto-fit-v2-*.json`。保留手动曝光、对比度、高光、阴影、色温、饱和度及所有原照片。已有 v2 亮度辅助记录不会被重复停用。

可选「亮度辅助」仅对明显偏暗的输出做 0 至 +0.75 EV 的有限提亮，不自动压暗或降低饱和度。夜景和低调画面保守跳过；每次补偿用实际渲染结果检查高光剪切、暗部和中间调分离，不满足条件则减小或取消。它仍是统计辅助，不能替代拍摄意图判断。手动滑杆不会触发反复重算，主动点「重新评估」才按当前手动参数重评。

辅助只作用于所选照片，预览和导出共用保存的补偿。DNG 保持原生高精度处理与原尺寸 TIFF16 导出。杂志、适应窗口及胶卷边框延续 0.15 的功能。

本次另用 REA 与 Ghidra 对用户提供的 SpektraLab 1.3.3 安装包进行静态核对，提取 RAW 初始化函数并对照公开源码；具体证据与平台边界见 [安装包逆向核对](docs/SPEKTRALAB-1.3.3-AUDIT.md)。这不代表已在 Windows 执行 macOS Metal 或实现全部原版功能。

## 0.15.0：学习杂志风格，并增加适应窗口

杂志排版不再把所有照片套进参考图的同一组位置。统一保留纸色、留白、局部对齐和大小节奏，用错落分组、对角阅读、错位分栏、宽幅引导、分散组团、竖幅主图六类构图规则，按照片数量与横竖比例评估图片利用率和主次关系。每组会生成多种比例方案，并选择适合素材的方案。

再次点击「一键排版」会换一种构图；相邻杂志页避免相同构图。一轮后继续探索新的分组比例与间距。保存和重启保持当前页面，只有主动排版才换版，撤销/重做包含换版状态。依然完整显示照片，不裁切、不改变调色。这里分析的是数量和横竖比例，不宣称识别人物、场景或照片语义。

新增独立模式「适应窗口」：沿用同一套杂志构图规则，将纸页比例换成当前灯箱可见区域的宽高，把胶片库全部照片（包括未放上台面的照片）错落排进同一屏。窗口尺寸变化或调色面板打开、关闭时自动重排，并保持当前构图方向；再次点「一键排版」可换一版。默认使用干净照片边缘，单张切回胶卷边框后也会完整纳入布局。为边界、页脚和选择工具留出空间，照片多时会缩小，仍可放大查看。

「适应窗口」明确作用于全部照片布局；杂志、网格、联系表仍只排列所选照片，未选择时排列台面照片。主动移出台面的照片在自动缩放时保持移出，再点一次「一键排版」会把全部照片放回。所有布局仅改变台面几何，原片、调色和照片导出保持不变。

## 0.14.0：错落杂志拼版

「一键排版 → 杂志」改为用户提供的竖版参考结构：顶部两张偏右、中间三张错落，下部左竖图配右侧宽横图、小横图。页面保留大块上下留白、浅灰纸底和 dose 页脚，每页最多八张，多张照片平衡分配到多页。

按照片横竖比例匹配位置，完整保留画面，不裁切或拉伸；因此不同素材可能在局部产生额外留白。杂志内默认显示干净照片边缘，胶卷齿孔偏好保留，可点选单张再用「齿孔」或「装框」切回胶片外观。网格、联系表延续胶片外观。

未选择时排台面全部照片，选择两张以上时只排所选照片。纸页参与显示全部、自动保存和撤销/重做；仍可逐张拖动、放大查看、调色。纸底、页脚和齿孔只在观片台上显示，单张照片导出不包含它们；导出布局 JSON 会保留纸页结构。当前没有新增合成整页图片/PDF 导出功能。

胶片模拟、自动适配、HEIC/DNG 解码和高精度导出流程保持 0.13.0 实现。视觉验收与交互测试见发行目录的「排版验证.md」。

## 0.13.0：逐张自动适配（历史实现，已于 0.16 停用）

光谱模式已有原版输入测光，默认「平衡」；它决定照片进入胶片时的曝光，不负责让不同胶片、相纸的最终亮度与原片保持一致。本版新增 dose 的「自动适配」，对比原片与胶片成片的亮度和色彩，保存逐张补偿值。它是可关闭的成片校正，未改动原版胶片材料、测光模型和显影核心。

- 点选照片 →「胶片调色」→「胶片与相纸」。新选择此模式时默认启用自动适配；已有调色记录保持原样，需手动勾选。关闭可直接回到原版处理结果。
- 更换胶片、相纸、测光或画幅时重新分析。手动曝光、高光、阴影、对比度、色温、饱和度及印相亮度在固定补偿之上调整，连续拖动时不会反复自动抵消；需要按当前参数重算时点「重新适配」。
- 每张照片独立测量和保存，只改变选中的照片。预览与导出共用同一补偿；分析时保留已有图像，不显示加载卡片。完成前导出按钮暂不可用，也可关闭自动适配立即导出原版结果。
- 亮度使用原片的线性亮度中位数作参考，补偿范围 ±1.25 EV，保留黑白端点；不会把夜景统一拉到白天亮度。色彩参考包含暗部的第 75 百分位饱和度，保留风格余量，仅在明显过重时降低色彩，系数范围 0.45–1。
- 光谱校正在原生 ProPhoto 浮点阶段完成，仍支持 DNG 原尺寸 16 位 TIFF；LUT 模式也支持自动适配，保持其 8 位 sRGB 处理边界。

这是有边界的图像统计校正，不识别人脸或主体，也不能判断拍摄者的曝光意图。已经剪切的源文件或胶片高光不能靠它恢复，极端照片仍可手动微调。验证范围和同图对照见发行目录「自动适配验证.md」。

## 0.12.0：彩色输出与显示对齐

修复了输出边界的二次高光亮度压缩。按原版 ColourManagement.swift，在胶片引擎已处理工作空间亮度后，导出至 sRGB 等目标空间时只保留色度压缩，关闭重复的亮度压缩。

预览改为保留原生 16 位 ProPhoto 样本并嵌入 ICC，通过无损 PNG 传递到浏览器色彩管理；灯箱使用 Display P3 Canvas。移除此前先转成 8 位 sRGB、再用 Sharp 缩小的光谱预览路径。显示与导出遵循原版的不同用途：画布做带配置文件的显示，文件按导出目标色域转换。

增加独立 CPU 模型验证，覆盖 20 款彩色胶片、JPEG / Apple DNG / Ricoh DNG 三个输入、配对相纸、正负曝光和印放等 300 个案例，最大误差为 1/65535。另对四个真实文件的目标色域输出做独立 CPU 对照，并核验 PNG16 传输逐样本无损、连续 DNG 预览和仅修改所选照片。这些结果不等于 macOS CIRAWFilter / ColorSync 的全帧实测对齐；详细范围见发行中的彩色流程核对报告。

对用户提供的 SpektraLab 1.3.3（build 18）安装包做了资源核对。原有 28 份材料数据的 JSON 内容与正式版一致，光谱常量逐字节一致；补齐此前 Windows 打包遗漏的 Kodak Tri-X 400、T-Max 100、Fujifilm Acros II、Ilford HP5 Plus 和 Ilford Multigrade IV RC 相纸。新增文件直接来自公开源码，与正式安装包中的文件逐字节一致，并保留其独立来源说明。

黑白胶片自动配对黑白相纸，按原版发送 2 号印放滤镜（C/M/Y = 0/0/68），使用单层颗粒与原版每款胶片的颗粒标定值。相纸列表禁用与所选胶片不兼容的选项；旧版配方需先「重置胶片」才能使用新黑白材料。仍只调整选中的照片。

源代码正式版本标签 spektralab-v1.3.3 与当前基准提交的 engine、modern_UI 目录树一致。以上是资源、源码和 Windows 渲染验证，不等同于 macOS Metal 实际输出已经逐像素对齐。

## 0.11.0：排版与胶卷边框

底栏新增「一键排版」：杂志、网格、联系表三种方式。杂志采用每页 12 列网格，以一张主图搭配辅助图，多页在台面上组成适合查看的整体；照片保持完整比例。未选择时排列台面全部照片，多选时只排列所选；只有一张被选中时会提示选择多张或点空白处。排版支持 Ctrl+Z / Ctrl+Shift+Z，并按原图库顺序编排，避免拖动造成的叠放顺序改变阅读顺序。

照片在灯箱上默认带胶卷齿孔；选中后可用「齿孔」按钮单独开关。横幅上下齿孔，竖幅左右齿孔；仍可切换白色幻灯框。边框只由灯箱 Canvas 绘制，缩略图、幻灯和照片导出都不添加齿孔。图片内容不裁切、不变形，排版会为实体边框预留间隙。

光谱流程继续修正：Provia、Velvia、Ektachrome、Kodachrome 正片采用直接扫描，不再经过相纸；明确选择负片时按材料档案选取配对相纸。印相亮度修改只提交变化的参数，以复用负片缓存。灯箱取消额外高光泛光层，默认亮度下不再改变处理结果。

本版保留简洁操作文案。底层调色精度、DNG 原尺寸 16 位 TIFF 和旧配方兼容延续。

## 高精度调色

光谱模式以 SpektraLab 提交 99c2d5c9883be485085895157279cc7c4eaa8db6 的产品流程为基准：

- 默认 Kodak Portra 400 + Kodak Supra Endura、平衡自动测光，正确启用 product_defaults，拍摄曝光不再被印相补偿抵消。
- 颗粒、卤光、眩光默认均为原版 1×；保留分层颗粒、散射和染料耦合默认设置。135 按 24 mm 短边与照片宽高比计算物理尺寸，120 按 56 mm 短边计算。
- 拍摄曝光 −8 至 +8 EV；印相亮度正值变亮，遵循原版 print_exposure = 2^(-stops)。支持平衡、中央、保护高光、保护阴影和手动测光。
- DNG 原文件直接交给 LibRaw 16 位解码，进入线性 ProPhoto float 工作空间。胶片/相纸结果以 RGBA16 进入浮点基础调整，然后才进行显示或输出色彩转换；不再先变成 8 位 sRGB 缓存。
- 高光、阴影、对比度、色温、饱和度遵循原版 Layer 2 的公式和顺序。
- 新增原始分辨率、16 位 ProPhoto TIFF 导出，嵌入 ICC。JPEG/PNG 为 8 位 sRGB，最长边 6000px。

新版光谱预览以带 ICC 的 ProPhoto PNG16 传输至 Display P3 Canvas，再由 Chromium / 系统按显示设备呈现；实际显示位深和色域取决于设备。交互使用原生 live 层（最少 800px），松开后补充适合查看尺寸的预览；保留上一帧直到新帧解码完成。最终导出走原生 full 层。不同分辨率会重新采样颗粒等空间效果。

## 打开与升级

1. 完整解压便携包，运行 dose.exe；保留同目录的全部文件。无需安装 Node.js 或 Python。
2. 添加照片，点击需要修改的照片，再打开「胶片调色」，选择「光谱胶片与相纸」。未选照片不会被修改，没有选择时禁用调色和导出。
3. 已保存的旧光谱配方继续使用旧版处理方式，以免照片无提示地改变。选中照片后点击「重置胶片」才能升级该照片，并重置为原版默认配方。新版配方按钮为「重置胶片」。
4. 拖动滑块连续预览；按住「看原图」比较；双击滑块恢复该项默认。旧照片和未选照片不受影响。「一键还原」关闭当前选中照片的全部调色。
5. 选中新版光谱照片后可导出 TIFF 16-bit。LUT 和旧版光谱只提供 JPEG/PNG，避免把 8 位路径包装成高精度输出。

沿用 %APPDATA%\lighttable-windows 本地图库、布局和 LUT；不修改或删除照片原文件。新建台面会先备份布局。旧安装目录可保留；0.16 首次启动会备份并停用旧版自动补偿，没有自动下载更新。

## 验证与边界

本次在 Windows x64 / NVIDIA RTX 5070 验证。原生 15 项 CTest、应用逻辑测试和实机 UI 检查随发行提供。

同图对照包括两张 JPEG、iPhone 12 Pro ProRAW（3024×4032）与 Ricoh GR III DNG（6020×4024）。参考使用独立的修改前 Windows 原生 host，直接传入从原版 Swift 源码转录的产品默认参数；与 dose 接入输出比较。另对六组基础调节做独立公式数值验证，检查预览/导出、16 位色阶、ICC、原分辨率和原文件不变。详细数值见同图验证页面和 verification/fidelity-report.json。

0.12.0 另以公开 spektrafilm CPU runtime 构建显式参数适配，输入同一份 float32 linear ProPhoto，验证胶片与印放核心；不依赖该包已移除的 service.schema。300 组核心对照和四组输出转换对照均通过。随机颗粒、眩光不参与 CPU 逐像素比较，另由原生测试与工作空间回归检查覆盖。没有 macOS Metal 实机输出，不能宣称跨平台逐像素完全一致。

需要 Vulkan GPU 及可用驱动；引擎不可用会报错，不会把保存的光谱配方静默替换为 LUT。C++ 运行库静态链接，无需另行下载 libc++.dll / libunwind.dll。

DNG 使用 LibRaw compatible 16-bit 路径，采用拍摄白平衡。保留高精度不等于无限 RAW 高光恢复；未开放 headroom Bayer 路径、HDR 增益图或完整原始元数据写回，也不写回 DNG。不能据两台设备的样本保证所有 DNG 变体兼容。损坏或不支持的文件会报告失败。文件上限 512MB，图像上限 1.5 亿像素。

HEIC/HEIF 继续采用本地 SDR 解码器读取首张静态图，缓存为 8 位；未保留 HDR 增益图、Live Photo 视频或景深。JPEG/PNG/TIFF/DNG 直接进入原生解码；WebP/AVIF/GIF 为兼容性在原尺寸转换成 RGB16 PNG，再进入光谱流程，这不增加源文件本来没有的精度。LUT 模式仍为 8 位 sRGB 调色。

未开放原版的场景纬度、对比度遮罩、DI、胶片片边、日期印字、局部蒙版、曲线、Display P3/HDR 校样。不要把本次核心胶片流程修复理解为整套 macOS App 的全部功能移植。

## 观片台与本地胶片库

- 照片/文件夹/系统拖放导入；JPG、PNG、TIFF、HEIC、HEIF、DNG、WebP、AVIF、GIF（静态首帧）。
- 灯箱、拖动、旋转、缩放、框选、多选、撤销/重做、装框和胶片袋。
- 放大镜、空格凑近、Tab 原倍率/8×；全屏幻灯、方向键切换、Esc 返回。
- 自动保存布局、导入/导出 JSON 布局。预览更新时保留已有照片，不绘制加载占位卡。
- 24 种光谱胶片与 9 种相纸/拷贝片；6 套 Pat David LUT、Cube / HaldCLUT 导入。

商业 Dehancer、RNI、DxO 仅保留官网入口，未内置其私有引擎。5207 是此前本机导入的 Gloam 官网公开展示 LUT，不代表 iOS 完整算法，不随便携包和源码包分发。个人 LUT 仍留在原本机目录；缺失配置会明确提示。

所有运行处理在本机完成，无账户、遥测或云上传。布局包含本地绝对路径，分享前自行检查。未签名、未覆盖全部 Windows 10/11 与 GPU，未验收超大图库。所有字体使用 Windows 系统字体。
