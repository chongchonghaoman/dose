# 标题

在 Windows 上调好胶片色，再排几页杂志

# 正文

dose 里内置了 Windows 版 SpektraLab。选一张照片打开「胶片显影」，就能试不同的胶片与相纸。图里这家居酒屋，用的是 Portra 400，门口的木色和红灯笼都很适合拿来试色。

调完点「完成并返回 dose」，照片就回到工作台，可以接着排版。显影结果单独保存成 16-bit TIFF，下次打开还能接着改这次的参数。

0.29 的杂志排版加上了主图。我拿这组日本日常照片试了一下，把居酒屋那张放大，几张小照片排在下面。前后各留一页，翻过去的时候，画面会松一些。

横片和竖片按原来的比例摆进页面，换版式时也会保留选好的主图。整组铺开看过，再挑一页重排，慢慢试到自己喜欢的样子。

排好就按页存成 JPEG 或 PNG，长边最高 4800 像素，分享时把导出的图片按顺序选上就行。

Windows 版下载在 GitHub：chongchonghaoman/dose。进入 Releases，下载后完整解压，打开 dose.exe。显影所需的运行文件已经放在包里。

项目已经开源。用着顺手的话，欢迎点个 Star。

# 置顶评论

下载：https://github.com/chongchonghaoman/dose/releases/latest

选择 dose-0.29.0-Windows-x64.zip，完整解压后打开 dose.exe。原生显影需要支持 Vulkan 的显卡与驱动。遇到问题可以在仓库提 Issue。
