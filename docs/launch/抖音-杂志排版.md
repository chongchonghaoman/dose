# 标题

把照片排成摄影杂志，这次可以逐页保存了

# 正文

dose 更新到 0.29 了。这次主要在做照片排版，我选了一组日本日常实拍来试：街边店铺、车厢里的乘客、樱花和住宅区铁道。六张照片排成三页，图里就是直接导出的效果。

第一张单独放一页，中间几张组成图组，最后再留一张收尾。纸面只放照片，空下来的地方就留着。整组摆在台面上，能一起看每页的大小和疏密。

居酒屋那张，我把它设成了主图。再换版式，它也会保留主要位置。其他照片跟着它重新安排，横片、竖片都保留原来的比例。某一页想再试试，也可以单独重排。

排好后点「导出页面」，每页保存成一张 JPEG 或 PNG，文件按顺序编号。长边最高可以选 4800 像素，发图时直接按页选就行。

dose 里也能调胶片色。LUT 列表用当前照片做预览，选好后调强度；内置的 SpektraLab 显影室可以继续调整胶片与相纸，完成后回到同一个工作台。

Windows 版已经开源，照片在本地处理。GitHub 搜索 chongchonghaoman/dose，进入 Releases 下载，完整解压后打开 dose.exe。

欢迎拿自己的一组照片试试。用着顺手的话，给项目点个 Star；排版遇到卡手的地方，也可以到仓库提出来。
