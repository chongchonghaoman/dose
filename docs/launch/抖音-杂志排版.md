# 标题

用 dose，给日常照片排几页杂志

# 正文

最近给 dose 做了杂志排版，拿一组日本日常照片试了试。奈良的店铺放在第一页，翻过去是居酒屋门口，最后用一条有阳光的街道收尾。六张照片，排了三页。

我把居酒屋那张设成了主图，门口的红灯笼和自行车放大来看，车厢、樱花和铁道排在下面。周围留着空白，照片之间也有了大小变化。

几页铺在台面上，可以一起看整组的效果。想换一种排法，点一下就能重排，选好的主图会保留。也可以只调整其中一页。

这次还加了按页保存。排好后导出成 JPEG 或 PNG，文件已经编好顺序，发图时一页页选就行，长边最高可以选 4800 像素。

想给照片换个颜色，可以打开 dose 的胶片风格列表，拿同一张照片试不同的 LUT。调好再放进版面，看看它和旁边几张合不合适。

dose 0.29 的 Windows 版已放到 GitHub。搜 chongchonghaoman/dose，在 Releases 下载，完整解压后打开 dose.exe。

可以拿最近拍的一组照片试试。用着顺手，欢迎给项目点个 Star。
