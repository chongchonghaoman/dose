# 开源基础与 EDR 二进制

基础Swift代码使用原MIT许可。Binaries/LightTableEDR.xcframework及其公开调用头文件采用Binaries/EDR-LICENSE.txt，允许作为观片台的一部分使用和分发未修改的二进制；不授予该组件源码许可。既有第三方组件、音频和模型仍遵循各自许可。

公开源码构建不需要私有目录，使用swift build或scripts/build-app.sh即可链接随附二进制。EDR核心实现、研究资料和数值参考测试不在公开源码包中；维护者单独验证后提供二进制及摘要清单。

## 维护者发布操作

1. 在私有开发区构建并验证模块，使用明确文件清单生成新的公开候选目录；不得直接复制整个开发区，不合并开发区Git历史。
2. 检查候选与现有公开仓库的差异，保留公开更新配置、既有许可和历史。同步时一并移除公开候选排除的私有数值测试，私有开发区保留原件。
3. 在公开仓库运行git config core.hooksPath Distribution/hooks，启用暂存区及待推送提交检查。检查读取Git中实际准备发布的内容，不仅检查工作区文件。
4. 编译和检查通过后，用scripts/prepare-release.sh准备ZIP和更新文件；脚本再次检查源码和安装包。提交、推送、上传和正式发布仍需用户授权。

检查用于避免误公开源码和开发资料；二进制发行不构成无法逆向的保证。MIT许可只覆盖开源基础，不应把整个安装包描述为MIT开源。
