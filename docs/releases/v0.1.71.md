# 观片台 v0.1.71

## 台面多选与批量移除

- 普通指针下，⌘点选多张或Shift拖动框选，再按Delete或点击「移出台面」。底栏照片和磁盘原图保留，相册页整页收回。
- 多选显示边框和数量；点击空白或Esc取消选择。空白处直接拖动仍可平移台面。

## 大放大镜连续变焦

- 按住空格后切换原倍率／8×，画面约0.26秒连续推近或拉远，保持鼠标观察点与镜口位置。
- 支持点击、拖动倍率滑块及Tab切换；减少动态效果时立即切换。

## 更新后新功能指引

- 首次打开本版本，显示新功能卡片；可直接开始观片，或选择「看看怎么用」查看三步操作提示。
- 提示对应多选、批量移出与变焦位置，可前后翻、随时跳过；同一版本不再自动重复显示。
- 菜单「帮助 → 本次更新…」可随时重看。无需添加示例照片，不修改图库、布局或原图。

macOS 14+，Apple Silicon。已有v0.1.70用户可从应用菜单「检查更新…」下载并安装；开启自动检查后，启动应用会检查新版。
