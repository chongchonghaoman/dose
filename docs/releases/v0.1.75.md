# 观片台 v0.1.75

本次调整开灯瞬间的过曝和倍率切换的选中样式。

- 开灯瞬间过曝调整为最高 **+0.8 EV**，保留原有点亮和回落节奏，随后恢复稳定亮度。
- 「原倍率 / 8×」选中项改为与「幻灯片」按钮一致的黑底白字，当前倍率更容易辨认；点击、拖动和 Tab 切换方式保持。
- 首次打开显示简短更新说明；本版没有新增操作，不提供额外的操作指引。菜单「帮助 → 本次更新…」可重看说明。

macOS 14+，Apple Silicon（M 系列）。已有支持更新的公开版可通过「观片台 → 检查更新…」下载并安装重启；手动安装请下载本页的 `LightTable-v0.1.75-macOS-arm64.zip`，退出旧版后解压使用。
