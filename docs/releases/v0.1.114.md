# 观片台 v0.1.114：诊断采样

遇到卡顿、放大镜异常或显示问题时，可以录一份诊断记录发给维护者，帮助定位你设备上的问题。

1. 点屏幕左上角菜单栏「观片台」，选择「开始诊断采样…」。
2. 照常拖片、开关放大镜或 EDR，让问题再出现一次。每次最多 15 分钟。
3. 回到「观片台」菜单，选择「停止并上传诊断…」，查看将发送的内容后确认上传。
4. **上传后，一定要把显示的诊断编号发给维护者。** 没有编号就找不到你的记录。

只记录应用与放大镜状态、EDR 开关、系统版本、芯片架构和每秒帧耗时汇总；不采集照片、截图、文件路径、鼠标坐标或电脑名。单份最多 5 MB，上传到维护者的私有存储，30 天后自动删除。网络失败时记录保留在本机，可从菜单重试；取消上传会删除记录。

首次启动会带你走一遍三步操作指引，走完才进入观片；之后可在「帮助 → 本次更新…」重看。可通过应用内「检查更新…」升级。
