# 观片台 v0.1.70

- 新增透光胶片图标：明亮奶白灯箱、深色胶片框与抽象透光色块。
- 新增应用内更新：每次启动后台检查 GitHub 正式版本，有新版时提示。点击「安装更新」下载，再选择「安装并重启应用」；菜单也可手动检查或关闭自动检查。
- 恢复幻灯切片声音：旧片出场时播放完整快门咔嚓，首张入场使用后半段，保留较轻音量与房间反射。
- 放大镜新增「原倍率 / 8×」滑块，仅在放大镜模式显示，紧挨放大镜按钮右侧。
- 支持点击、拖动及 Tab 切换大镜子倍率；按住空格凑近时也能切换。

macOS 14+，Apple Silicon。旧 v0.1.65 需手动安装本版本一次，后续才能使用应用内更新。
