# 观片台 v0.1.73

本次更新加入多底栏和取片收回，让台面更像真实观片台；同时调整镜片与薄片接触感，并补全六步操作指引。

## 多底栏与追加导入

- 「从文件夹导入」和「添加照片」把照片追加到当前底栏，保留已导入内容。
- 点击底栏标签右侧的 ➕ 新建一栏，点击标签切换。标签紧凑排列，➕、一键平铺和数量随新增底栏向右移动，超过宽度上限后滚动。
- 每栏独立保存照片与顺序；数量显示本栏剩余和总量。「一键平铺」使用当前底栏，并重新排列台面散片。

## 取片与原栏收回

- 从底栏拖到台面的照片会从底栏隐藏，像把胶片拿到灯板上；取消或无效拖放仍留在底栏。
- 点选台面照片按 Delete，或右键「收回底栏」，按原顺序回到最初拿出它的底栏。当前查看其他底栏也不改变收回位置。
- ⌘点选或 Shift拖动框选后可批量收回；放大镜模式下先按 A 切回普通指针。
- 收回会释放离台照片不再需要的模型高清预览，沿用既有缓存预算；磁盘原图保留。

## 点标签，Delete 删除整栏

- 点击要删除的底栏标签，再按 Delete，移除该栏及它已放到台面的散片。
- 磁盘原图、其他底栏和独立相册保留。点空白或按 Esc 取消底栏选择；点选台面照片后 Delete 仍是收回照片。
- 删除后清除删除目标，连续按 Delete 不会继续删除相邻栏。最后一栏删除后留下新空栏，可继续导入；进行中的导入不会恢复已删除底栏。

## 专业观片镜与薄片质感

- 放大镜中央 72% 半径保留清晰取样，外围逐渐产生轻微曲率；窄暗边、亮边与随观察位置变化的反光表现玻璃截面。
- 按住空格凑近，曲率与反光连续减弱并保留较轻效果。普通镜仍为 1.5×，大镜仍支持原倍率／8×，Tab 和倍率滑块保持原有操作。
- 薄侧沿有轻微厚薄变化，平贴、左下微翘和右下微翘三种形态随照片固定，重启或移动不会重新随机；照片画面不加框、不裁切、不变形。
- 材质共用三张 96×96 静态贴图，沿用已有镜片渲染和预览缓存，不增加实时模糊或常驻动画时钟。
