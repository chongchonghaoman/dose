# 观片台 v0.1.107

延续全新「背光 EDR」：亮部更通透，高光保留层次，暗部保持深度，留住照片的细节、色彩与对比度。

- **EDR 亮度自由调节**：默认120%，可用顶部滑块在10%–160%之间调整。双击恢复当前模式默认值；普通模式与EDR分别保留本次使用的亮度。
- **启动默认关闭 EDR**：点击顶部「背光 EDR」或按E开启，按住空格凑近时也可切换对照。
- **幻灯片采用 EDR**：进入时自动启用，使用设置好的EDR亮度，返回保留台面原状态。
- **优化幻灯片音效**：进入加载阶段保持静音，首张落下延用原有音效，换片采用较轻的机械按键声。

更新说明沿用上一版样式，补充亮度调节及音效优化。可在「帮助 → 本次更新…」重看。

运行环境：macOS 14或更新版本，预编译包面向Apple Silicon。照片与布局保留在本机；更新不会改写原图。
