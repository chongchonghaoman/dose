# 观片台 v0.1.74

本次更新把底栏单张删除放到 Delete 键，整栏删除改用右键菜单；同时带来透明镜缘、适度外围折射，以及镜内闪烁和多图卡顿修复。

## 单张按 Delete，整栏用右键

- 点选底栏照片或文件名，出现选中框后按 **Delete**，删除该张；照片右键「从底栏删除」也可使用。
- 右键底栏标签，选择 **「删除底栏」**，才会删除整栏。刚导入文件夹或仅点击标签后按 Delete，不再删除整栏。
- 删除底栏照片或整栏时，会一并移除台面对应散片；其他底栏、独立相册和磁盘原图保留。
- 删除后不自动选中下一张，连续按 Delete 不会继续删除相邻照片。点击空白、按 Esc、切换底栏、选择台面或开始拖片会清除底栏照片选择。
- **台面上的 Delete 仍是收回**：选中台面照片后按 Delete，照片按原顺序回到原底栏，支持多选收回。

## 透明镜片与适度折射

- 镜缘更通透，保留柔和反光；调整镜内背景和普通放大镜指针效果。
- 中心保持清晰，外围曲率比上一正式版更容易看见，同时收敛过强的拉伸感；凑近时保留较轻的折射与反光。
- 普通镜仍为 1.5×，按住空格凑近、松开退回；Tab 或倍率控件切换「原倍率／8×」。

## 显示稳定性与多图响应

- 修复镜内画面的呈现顺序问题，减少闪烁；补全画面尺寸变化后的恢复处理。
- 画面暂时无法完成时尝试恢复，恢复次数有上限。
- 优化多图排序和照片查询，改善浏览、拖动和整理时的响应。
