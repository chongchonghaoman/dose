# 观片台 v0.1.87

新增「回到过去」：将一张照片生成可以小范围移动视角的高斯场景，在黑暗中慢慢逐粒显现。

## 如何使用

1. 点击幻灯片右侧的蓝紫色动态「回到过去」按钮。
2. 从下方底栏选择照片，拖入上方播放区。程序读取原始照片，不使用底栏缩略图。
3. 首次使用需联网下载运行环境和 SHARP 模型；完成后显示首次推理状态。后续版本复用已下载环境与模型。
4. 等待生成和场景加载完成，黑场中逐粒显现初始视角。
5. 左键拖动小幅旋转，右键拖动平移，滚轮或触控板捏合缩放，双击复位；按 Esc 返回观片台。

## 体验调整

- 使用 PlayCanvas 渲染和基于 OOOSplat 的交互控制，改善场景播放流畅度。
- 降低旋转、平移和缩放速度；左右旋转与平移限制在原视角附近，前后缩放不受该范围限制。
- 单张照片无法还原未拍摄区域，小幅移动仍可能露出空洞或变形；本版不包含场景补全。
- 动态入口保留蓝紫渐变、流动光点与柔光，文字居中，移除白色圆圈。
- 改善幻灯片对底栏和画布照片的收集，并修复关灯时的入场显示。
- 更新首次启动说明卡；菜单「帮助 → 本次更新…」可重看。

## 运行要求与下载

- macOS 14 或更新版本，Apple Silicon（M 系列）。
- 安装包：`LightTable-v0.1.87-macOS-arm64.zip`。已有更新功能的版本可在「观片台 → 检查更新…」中升级。
- 无需 Xcode。SHARP 环境与模型按需下载，不包含在安装包中；下载需要网络和额外磁盘空间。
- 照片在本机处理。生成过程可能使用较多内存，提供低内存处理路径，没有 16 GB 硬门槛；8 GB 设备尚未实测，耗时和能否完成取决于设备及照片。
- SHARP 模型仅限非商业科学研究；模型许可明确排除产品开发或商业产品／服务用途。首次下载和本机运行不改变这些限制。详见随附的 `LICENSE_MODEL` 与仓库第三方许可说明。
- 应用使用 ad-hoc 签名，未经过 Apple 公证；更新源和安装包提供 Sparkle 签名验证。
