# v0.1.114 操作指引：诊断采样

## 什么时候用

放大镜卡住、画面掉帧、EDR 显示异常，或其他只在你这台 Mac 上出现的问题。

## 步骤

1. **开始**：点屏幕左上角菜单栏「观片台」→「开始诊断采样…」。
2. **复现**：像平常一样拖片、开关放大镜（V）、按住空格凑近、切换背光 EDR，直到问题再出现一次。采样最长 15 分钟，到时自动停止。
3. **上传**：「观片台」→「停止并上传诊断…」。弹窗列出将发送的数据类别，点「上传」；点「取消并删除」会丢弃这次记录。
4. **发送编号**：上传成功后弹窗显示「诊断编号：xxxxxxxx-xxxx-…」。**务必把这串编号发给维护者**（截图即可），并简单描述遇到的问题。

## 上传失败

记录会保留在本机。稍后从「观片台」→「上传待处理诊断…」重试。观片台意外退出后，下次启动也会提示找到未完成的记录，7 天后自动清理。

## 隐私

只记录白名单内的状态变化和每秒帧统计，不含照片、截图、文件路径、鼠标坐标、电脑名或 EDR 私有参数。记录保存在维护者的私有存储，30 天后自动删除。

## 首次启动指引

升级后第一次打开会显示更新卡片，点「看看怎么用」按三步提示走完才进入观片；中途退出，下次启动会再次出现。走完后可在「帮助 → 本次更新…」随时重看。

## 升级

1. 已安装 v0.1.70 及以上：「观片台 → 检查更新…」，下载后「安装并重启」。
2. 手动安装：从 v0.1.114 Release 下载 `LightTable-v0.1.114-macOS-arm64.zip`，退出旧版，解压后打开「观片台.app」。
