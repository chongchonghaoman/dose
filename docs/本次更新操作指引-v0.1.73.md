# v0.1.73 操作指引

1. **导入和分栏**：点击「从文件夹导入」，照片追加到当前底栏。点标签右侧的 ➕ 新建一栏，点击底栏标签切换。
2. **取片**：从底栏拖照片到台面，放好后底栏不再显示这张照片；取消拖动则仍留在底栏。「余 / 总」显示本栏剩余数量和总量。
3. **收回照片**：点选台面照片后按 Delete，或右键「收回底栏」，照片按原顺序回到原来的底栏。⌘点选多张、Shift拖动框选后可一起收回；放大镜模式下先按 A 切回普通指针。
4. **删除底栏**：点击要删除的底栏标签，再按 Delete。该底栏及它已放上台面的散片一起移除，磁盘原图保留；其他底栏和独立相册保留。点空白或按 Esc 取消底栏选择。最后一栏删除后会留下新空栏，仍可导入。
5. **观察镜片**：点击放大镜或按 V，移到照片上观察。按住空格凑近，松开退回；右侧倍率控件或 Tab 切换「原倍率 / 8×」，普通小放大镜仍为 1.5×。
6. **重看说明**：选择「帮助 → 本次更新」。操作提示可跳过或回退，不必完成实际删除。

## 升级

1. 已有支持更新的公开版：在「观片台 → 检查更新…」查看 v0.1.73，按窗口提示下载并安装重启。
2. 手动安装：从本仓库 v0.1.73 Release 下载 Apple Silicon ZIP，退出旧版，解压后打开「观片台.app」，也可拖入「应用程序」。
3. 首次打开显示本次更新卡，点击「看看怎么用」查看六步指引，或「开始观片」直接进入。看过早期 0.1.73 测试版的用户也会收到新增说明；本次内容只自动展示一次。
