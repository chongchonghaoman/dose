# v0.1.74 操作指引

## 照片与底栏

1. **导入和分栏**：点击「从文件夹导入」或「添加照片」，照片追加到当前底栏。点标签右侧的 ➕ 新建一栏，点击标签切换。
2. **取到台面**：从底栏拖照片到台面，放好后底栏隐藏这张照片；取消拖动则仍留在底栏。「余 / 总」显示本栏剩余数量和总量。
3. **从台面收回**：点选台面照片后按 Delete，或右键「收回底栏」，照片按原顺序回到原底栏。⌘点选或 Shift 框选后可批量收回；放大镜模式下先按 A 切回普通指针。
4. **删除单张**：点选底栏照片或文件名，看到选中框后按 Delete；也可以右键照片选择「从底栏删除」。台面上同张散片一并移除，其他底栏、独立相册和磁盘原图保留。
5. **删除整栏**：右键底栏标签 →「删除底栏」。整栏与它已放到台面的散片一起移除；其他底栏、独立相册和磁盘原图保留。最后一栏删除后留下新空栏，可继续导入。
6. **取消选中**：点空白或按 Esc。切栏、点台面或开始拖片也会清除底栏照片选择。刚导入或只点标签后按 Delete 不会删除整栏；删除单张后不会自动选中下一张。

## 放大镜与说明

1. 点击放大镜或按 V，移到照片上观察清晰中心与外围折射。
2. 按住空格凑近，松开退回。右侧倍率控件或 Tab 切换「原倍率 / 8×」，普通小放大镜仍为 1.5×。
3. 选择「帮助 → 本次更新…」重看更新卡和六步提示。提示可跳过或回退，不必实际删除照片。

## 升级

1. 已有支持更新的公开版：打开「观片台 → 检查更新…」，查看 v0.1.74 后按提示下载、安装并重启。
2. 手动安装：从本仓库 v0.1.74 Release 下载 `LightTable-v0.1.74-macOS-arm64.zip`，退出旧版，解压后打开「观片台.app」，也可拖入「应用程序」。0.1.74 测试包使用此方式换成正式版。
3. 首次打开显示本次更新卡。点击「看看怎么用」查看六步提示，或「开始观片」直接进入；本次内容只自动展示一次，旧版记录保留。
