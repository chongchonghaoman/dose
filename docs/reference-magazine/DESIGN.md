# dose reference magazine

## 1. Visual Theme & Atmosphere
Learn the reference's editorial language: portrait paper, asymmetric groups, local alignment, size hierarchy and deliberate empty space. The reference is evidence of a style, not a fixed position map.
## 2. Color
Paper #e8e6e3, folios #737a7c. The photos retain their existing colour processing; page colour never grades their pixels. Existing dose app chrome stays unchanged.
## 3. Typography
Pages contain no generated text, branding or folios. Controls and page counts remain in the app interface, outside the paper.
## 4. Spacing & Grid
Page ratio 849:1200, runtime width 1000. Twelve shared parent columns and a baseline grid align actual photo edges. Headroom and body clusters change by composition; no fixed eight-photo slot coordinates.
## 5. Layout & Composition
Plan the book before fitting images: sparse opening and closing pages, with grouped and quieter pages in between. Preserve source sequence across page membership. A designated main image has a dedicated region and companions with smaller actual image areas. Other groups use six grid-based compositions. Repeated clicks change the composition; local reflow retains page membership and the main photo. Saved pages never reshuffle on their own.
## 6. Components
Paper and folios are display-only. Both modes default to clean print edges; film controls remain available. “适应窗口” uses the same editorial grammar on ONE paper sized to the current stage, placing every library photo on that paper. The page fits actual stage width/height, reserving room for selection tools. It is not a rows/grid mode.
## 7. Motion & Interaction
Magazine: one click lays out the table or selected photos; another click changes composition. Window mode: explicit action brings all library photos onto the table; resize or panel changes reflow the current table. Layout, variant and page state support save/load and undo/redo. Preserve photo edits and source files.
## 8. Voice & Brand
Keep “杂志” under “一键排版”. The selected-photo toolbar offers “设为主图”. A compact control outside the paper shows page count and “导出页面”. No generated text appears on the paper.
## 9. Anti-patterns
No single reference template repeated across the collection; no mirror-only or reorder-only variation; no loading cards; no added doodles or copied footer brand; no automatic colour changes. Both modes retain editorial clusters and hierarchy; changing window dimensions never switches the composition to a uniform grid.
