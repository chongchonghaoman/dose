# Flipin Zine 视觉研究与 dose 排版建议

研究日期：2026-10-28。

范围：用户要求学习 Flipin 的排版、杂志艺术与视觉效果。本记录是参考研究和后续设计建议；本次没有修改 dose 排版代码，也没有把建议标记为已经实现。

## 1. 证据范围

- [Flipin 官方网站与交互演示](https://flipin.cn/download/)：实际查看首页、框选照片池、自动成册和翻页。选中 7 张官方示例照片，页面提示生成 3 页；查看了开篇跨页和末页。
- [Flipin 官方 App Store 页面](https://apps.apple.com/cn/app/flipin-3%E5%88%86%E9%92%9F%E5%81%9A%E6%88%90%E4%B8%80%E6%9C%ACzine/id6798570638)：查看 6 张官方展示图及功能说明。
- 本地对照：`design-contract.md`、`DESIGN.md`，以及本次对话中用户对九宫格、图片尺寸、网格系统、放大镜的要求。

没有安装或完整体验 iPhone App；官网演示也不能代表全部内页模板。没有证据证明 Flipin 使用何种智能分组、网格列数或布局优化算法。

## 2. 实际观察

### 隐藏的对齐关系支撑不对称构图

官网 Style B 的开篇左页，上方是大标题，下方是一张接近页宽的主图；右页有一张较大照片和三张小照片。照片并不占据整齐等大的格子，但存在明确关系：

- 右页上方的大图与右侧小图底边对齐。
- 右侧两张小图共用同一列，宽度相同。
- 中间小图的右边与上方大图的右边对齐。
- 图号依附照片边缘，字号明显小于封面标题。

在本次 1280 × 720 视口中，右页上方两图底边约为 319.35 px；两张右侧小图左边约为 887.58 px、宽约 97.67 px；中间小图和上方大图右边均约为 850.98 px。这些测量仅用于核实对齐关系，不是 dose 应复制的坐标或尺寸。

因此可学习的是共享边线、宽度档位和视觉主次，不能把“错落”解释成任意坐标、旋转或随机间距。

### 主图、辅图与空白各有角色

左页的大图承担主要观看内容；右页的小图补充细节。空白集中在标题与图组之间，以及图组的阅读路径上。照片之间存在明显的大小差异，却没有把每张照片都缩成同样的小缩略图。

演示的末页只有两张图片并保留较多空白。这可以作为小书收尾的参考，不能直接套用到要求均匀覆盖的九宫格。

### 书页本身与展示环境分层

官网预览有中缝、轻微书页阴影，背后的照片池被模糊；书页上的照片和文字仍然清楚。App Store 展示图包含封面、跨页、书架，以及底层背景编辑界面。

可迁移的原则：让阅读对象清楚、有边界；立体效果主要服务于预览。不能由演示推断其全部导出格式一定如何处理阴影或书脊。

### 风格是一组连贯选择

官方展示同时出现清爽白纸、鲜明色块封面、照片拼贴和装饰边框；官网的手绘标题及黄色小图形偏轻松、私人出版物的气质。不同风格共享“照片成为一本可收藏的小书”这个组织方式，而不是给同一个位置模板换背景色。

对 dose 应吸收这种私人摄影小刊的气质，继续使用已经确定的品牌、纸色和操作界面。无需复制 Flipin 的黄色、苹果图形、文案或装饰素材。

### 自动生成之后仍可编辑

官方说明支持改变封面和背景、增添照片和页面、替换内页模板与照片、编辑文字、抠图与自由排布，并支持 JPG、MP4、PDF 导出。这是功能说明证据，不是本次逐项实测。

值得借鉴的是“先获得完整作品，再进行局部调整”。已有照片编辑内容、用户文字和选择应在重新排版后保留。

## 3. dose 应采用的设计规则（建议，尚未实施）

### 先确定页面角色，再选择满足约束的构图

建立有限而可组合的版式家族：

| 家族 | 适用内容 | 核心关系 |
|---|---|---|
| 主图页 | 一张重点照片，少量补充 | 主图占优，辅图沿共享边线组织 |
| 对页 / 双图页 | 两张有关联的照片 | 等高或等宽，可在尺度上有主次 |
| 图组页 | 一组连续场景 | 列宽、行高、图距统一，有清晰阅读路径 |
| 序列页 | 连拍、动作、细节变化 | 保持原有顺序，连续观看 |
| 拼贴页 | 用户选择的生活碎片 | 基础图组守网格，装饰层可局部打破边界 |
| 收尾页 | 少量照片、一个结束画面 | 适度降低密度，保持重点可读 |

这些家族是 dose 的设计建议，不是对 Flipin 模板目录的转录。

建议沿用可细分的 12 栏结构，让照片以不同跨栏宽度组合，并通过共同基线对齐。12 栏并非本次对 Flipin 的测量结论。页边距、列间距、基线间距由同一尺度系统定义，禁止为每张照片各自生成随机间距。

在固定网格下改变主图位置、跨栏宽度、组图方向、密度和阅读路径。重新智能排版应换构图家族或有效组合，不能只打乱照片顺序或左右镜像。

### 让照片内容参与选择，但区分真实能力

可首先使用已经拥有的宽高比、照片顺序、用户选中的重点照片；具备可靠元数据时可辅助按时间分组。颜色、场景和人物关系可以作为未来增强，不应在未实现识别能力时宣称已经智能理解照片。

重点照片获得更大的可见面积。默认完整展示照片；任何裁切应明确且可调整，不能为了填满网格悄悄裁掉主体。

### 不同模式采用不同密度目标

| 模式 | 应优化的目标 | 必须避免 |
|---|---|---|
| 杂志 | 单页主次与整本阅读节奏 | 每页同密度、同构图；把所有小图塞在一页 |
| 九页杂志 | 全库照片完整分配到九页，页与页有变化 | 一页过密、另一页只有一张且无合理目的 |
| 适应窗口 | 当前窗口中全库照片可辨认、空间均衡 | 大量不可用空白；仅在角落形成密集小图堆 |
| 朋友圈分割 | 1:1 全局构图、九个切片均衡且独立可看 | 把已有长页面缩小截图；单格空洞、照片跨切线时主体断裂 |

九宫格应先在完整正方形上重新布局，同时检查九个切片中的照片面积和视觉重量。均衡不要求九格完全相同，但每格应有足够内容，不应出现一格被大图占满、其余几格全是极小照片的失衡。

对于 122 张照片全部进入九宫格的要求，平均每个切片约 13.6 张，图片大小有客观上限。优先缩短无效间距、减少无目的留白、合理分组；不能以丢照片、重复照片或假称全部都能很大来掩盖容量限制。

### 放大镜作为可编辑的焦点层

九宫格的基础构图先满足网格与密度，再加入放大镜。用户可以自由移动、调整尺寸与倍率，并保留在导出画面中。初始化时应明确对准所选照片，避免镜内大部分为空白。重新排版应维护其与重点照片的关系，并保留用户已经调整的状态；具体跟随策略需要实现时通过交互检查。

### 文字与装饰服从照片

只显示有内容价值的标题、日期、地点、用户文字或必要页码。未提供内容时不生成空泛的英文标题、情绪口号和开发过程说明。纸面默认安静；手绘、抠图和边框应作为可选表现，不能对所有照片自动添加。

## 4. 后续实施时的验收方式

- 对同一组照片展示不同家族的布局：看得到结构差异，且仍有共享边线、宽度档位和一致间距。
- 用横图为主、竖图为主、混合比例及大量照片集合检查；比较实际最小照片尺寸，而不只看照片外部占位框。
- 杂志检查连续页面的节奏；九宫格同时检查完整方图和单独九张输出。具体密度阈值应根据实际输出尺寸和视觉对照制定，不能在研究阶段伪造“已达标”指标。
- 验证没有漏图、重复图、意外裁切、重叠，以及选中状态、照片调色、用户文字和原文件是否保留。
- 锁定布局后的保存、重开和导出应保持一致；用户没有主动重排时不自动改变构图。
- 放大镜需用真实交互和导出图核验位置、尺寸、倍率及切片衔接。

本研究明确的改进顺序：先改善构图家族与对齐关系，再改善照片分组和密度选择，最后考虑翻页、纸张与装饰表现。书脊阴影不能替代好排版。
