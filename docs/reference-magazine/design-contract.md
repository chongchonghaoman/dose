# Decision record

Goal: learn the user's supplied magazine style and generate varied compositions, plus a separate mode fitting every photo to the current visible window. The user explicitly rejected the 0.14 fixed reference template.

Audience: the dose user organizing personal photographs. Keep asymmetry, intentional whitespace, local alignment, hierarchy, paper and sparse folios. Change composition, reading direction, group proportions and emphasis for each collection. Do not copy fixed photo positions, sample photographs, embedded doodles or FRIENDS MAGAZINE wording.

| Evidence | Status | Decision |
|---|---|---|
| Supplied clipboard image, 849 × 1200 | provided and observed | Keep editorial relationships and paper language, not its eight slot positions |
| User correction: learn style, do not make everything identical | provided | Generate different reading paths and hierarchies, prove them with the same photos |
| User request: another mode sized to the current displayed area | provided | Separate adaptive window fitting from magazine composition |
| Photo contents and white doodles | observed | These belong to the sample photographs; do not generate them or alter user photos |
| Paper brand and wording | observed | Adapt footer to dose; do not copy the reference's brand |
| Arbitrary user photo ratios | inferred | Contain each full photo inside slots; match orientations automatically, allowing extra whitespace |

The source shape and reference composition cannot both be filled edge to edge for arbitrary aspect ratios without cropping. Preserve full photographs and accept local whitespace. This is an explicit implementation tradeoff, not a claim of identical output for all collections.

Acceptance: same eight photos produce six clearly different compositions and size hierarchies; no overlap/lost IDs; saved result stable; selected-only magazine layout, undo and restart work. Window mode includes unplaced library photos, fits full frame bounds at wide/tall/compact sizes, and reacts to panel width. No photo edits or source bytes change. No new whole-page image/PDF export is inferred.
