# 阿里云诊断接收函数

此目录只接收观片台主动提交的诊断 JSON，并写入独立私有 OSS Bucket。它不读取照片、不提供公开查询，也不连接腾讯云排队小程序。

## 本地验证

```sh
npm install
npm test
```

部署前在 Node.js 20 环境运行 `npm ci --omit=dev`，将此目录连同生成的 `node_modules/` 一起打包上传；不要把本地 `node_modules` 提交到源码仓库。

## 阿里云手动配置

1. 在阿里云 OSS 创建独立 Bucket，地域与函数保持一致，读写权限设为“私有”。
2. 创建仅能向该 Bucket 写入对象的 RAM 角色，并将角色绑定到函数计算服务；不要创建或填写长期 AccessKey。
3. 使用 Node.js 20 创建函数，入口文件为 `index.mjs`，处理函数为 `handler`，配置 `OSS_REGION`（`ali-oss` 格式，如 `oss-cn-hangzhou`，不是 `cn-hangzhou`）与 `OSS_BUCKET` 环境变量；设置最小实例数为 0。
4. 创建 HTTPS HTTP 触发器，仅由客户端发送 `POST` JSON。上传地址是公开接收入口，报告内容不会通过接口读回。
5. 在 OSS 生命周期规则中设置对象创建 30 天后过期。
6. 将函数的 HTTPS 触发器地址作为 `LT_DIAGNOSTICS_UPLOAD_URL` 传给 `scripts/build-app.sh`，再构建给用户试用的 App。
7. 在阿里云费用中心设置账单告警，并检查函数调用、流量和 OSS 请求费用；本方案没有月费用绝对上限。

HTTP 触发器使用免认证方式时，拿到触发器 URL 的人都能调用；URL 会随测试 App 分发，因此不能把它当作访问密钥。函数会拒绝读取、拒绝未知字段并限制每份请求 5 MB，但当前没有登录和提交频次配额，恶意或误操作的高频提交仍可能产生费用。若后续要限制费用，需要在阿里云侧另加调用配额/限流，或暂停触发器。

函数执行角色凭据由运行时提供；客户端不包含任何云凭据。此功能不限制上传次数，每份报告由客户端和服务端共同限制在 5 MB，云费用仍按实际调用和存储用量计算。
